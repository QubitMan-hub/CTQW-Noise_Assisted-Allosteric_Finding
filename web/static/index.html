Glossary

Quantum walk
Signal spreading through the contact network as a wave, over many residues at once.
γ, dephasing rate
How fast noise scrambles the walker's phases. 0 is fully quantum; large values make it hop classically, then freeze.
Transport hump
The signal reaching distant residues peaks at an in-between γ: a little noise helps.
Allosteric site
A pocket away from the active site where a binding molecule still changes what the protein does.
ROC AUC
The chance that a known allosteric residue gets more signal than a random other residue. 0.5 is a coin flip, 1 is perfect.
Baselines
Simple rankings without any walk (number of contacts, distance to the active site). The walk should beat them.
Random control
The same walk with random site energies. If it shows the same hump, the hump is not about the protein's chemistry.
